# D1 — Individual Discovery — &lt;student&gt;

Your individual discovery repo for NPD 2026F. Find and frame a real problem.

## Where things live
- `problem-finding.md` — your Problem Finding & Vetting (D1a): the list and the pick
- `opportunity-brief.md` — your Opportunity Recognition (D1b): the analysis
- `pitch/outline.md` — your pitch content draft (D1c)
- `submission.md` — milestone notes + your presentation link
- `notes/` — your session log, written by `/otus-session-wrap`
- `INSTRUCTIONS.md` — the requirements (do not edit; OTUS keeps the master)

## Quick start
1. Open this repo in Claude Code or Codex (cloud/web is the no-install path).
2. Read `INSTRUCTIONS.md`.
3. Run `/otus-instructions` and start with D1a-1 — the problem you pick there is what
   the rest of the deliverable runs on.
4. Run `/otus-session-wrap` whenever you stop for the day.
5. When ready: `/otus-submit`.

This file is yours to edit.
